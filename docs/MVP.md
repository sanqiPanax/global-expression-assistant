# MVP scope · v0.2 / 2026-10-11

用户确认：使用系统输入法的语音转文字，只需要文本输入框；固定 X 平台和英语输出。其余采用收缩后的 MVP。

## Included

- 中文文本输入、编辑和显式确认（最多 6000 字符）。
- 单帖 / Thread（最多 6 条）；7 种风格：自然口语、专业简洁、幽默搞笑、轻松聊天、故事分享、克制犀利、温和真诚（2026-10-13 扩展）；默认忠实模式，可选 X 原生改写。
- 中文要点 / 回译辅助对照；英文手动编辑。
- 个人话题开关；输入和输出检查；明确区分待检查、检查失败和未发现命中项。
- 源文、英文或配置修改后检查失效；重新载入草稿也必须重新检查。
- 使用平台加权长度算法，单帖最多 280；链接、emoji、中文不能简单按字符串长度算。
- 逐条 / 全文复制；显式本机草稿保存、更新、删除和清空。
- 后端模型凭据；无凭据时固定演示数据，始终显示演示标识。
- 开源代码、MIT 许可证、运行说明、自动化验证；不部署公共付费接口。

## Deferred

录音、语音识别服务、原生 APP、账号、云同步、系统分享、自动打开 X、发布 API、排程、更多平台/语言、逐条重新生成、个人模型训练、音频文件导出、复杂版本时间线。

## 2026-10-14 notebook and learning extension

用户确认新增：已发布中英对照、搜索与主题标签、表达收藏、改写解释、同一想法两版、常用术语表、完整导出与恢复、英文TTS朗读。

- 发布记录由用户手动确认最终英文与发布时间；不自动发布、不验证实际发布成功。Thread 可以手动整理各条中文。
- 本机资料共享一个版本化存储结构，旧草稿迁移成功后才删除旧存储副本。
- 导入先完整校验再合并，相同ID保留新记录；重复导入幂等；存储失败不覆盖旧数据。
- 双版用两次顺序生成，各自检查；第二版失败保留第一版；请求期间用户修改文本时不覆盖当前编辑。
- 解释单独调用模型，不作为检查结论；只引用当前英文中存在的短语；文本或命中术语变化后提示解释过期。
- 术语只发送原文命中的固定写法，单次最多50个；修改命中映射使旧检查失效。
- TTS使用浏览器/系统英文音色，支持语速和停止；默认优先本机声音，在线音色按浏览器/系统政策处理。
- 搜索覆盖中文、英文、标签、收藏语境、术语；所有展示使用文本节点，导入不能注入HTML。

## Acceptance

1. 无模型凭据可运行演示，固定示例不能被误认为真实翻译。
2. 中文未确认时不可生成；修改中文会撤销确认。
3. 禁用话题命中会暂停生成/复制；修改个人规则需重新检查。
4. 英文编辑后不可沿用旧检查；超长不可复制。
5. 模型复检格式错误或超时不得显示通过；生成出的草稿尽量保留供重检。
6. 保存后刷新可找到本机草稿；再次保存更新同一条；删除有确认。
7. 390px 手机屏幕无横向溢出；桌面使用两栏编辑界面。
8. API key 不进入浏览器、Git 或日志；内容不进入普通应用日志。
9. 通过基础逻辑、模拟模型 HTTP 和浏览器流程测试。

## Real-use evaluation still required

使用配置好的真实模型评估至少 20～30 条中文样本（AI 工具、项目名、数字、日期、否定句、谨慎表述、真实经历和长文）。记录生成耗时、改稿分钟数、名称/数字/语气是否保留、是否最终愿意发布，并和直接使用聊天工具比较。

初步价值目标：至少 60% 不需大幅重写；至少 50% 愿意发布。个人禁用主题在指定评测集内漏检 0 次只表示该评测集结果，不能对外宣称绝对安全。

## Current validation boundaries

2026-10-12 已接入本地 OpenCode Go / `minimax-m2.5`：一个合成样本的英文单帖与前后复检约 24.7 秒，输出 167 加权字符；将 20 改为 200 后的复检约 6.9 秒并正确标记错误；个人禁用加密货币主题在输入端拦截。新增会话路由头及单个 Markdown JSON 包裹兼容，16 项逻辑/HTTP 测试、24 项浏览器断言通过。

这只证明一个真实样本的连接与流程，不替代 20–30 条真实中文样本评测。真实写作质量、Thread 质量、稳定延迟、费用与留存政策仍需评估。凭据仅保存在被 Git 忽略的本地 `.env` 中。
